# Open-source contribution simulation

Course: **Git & Collaborative Development** (Beginner, 12 hours).

Take a small issue from branch to pull request, review, conflict resolution, and merge.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/git-collaboration.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] The change lives on a branch.
- [ ] The pull request says what changed and how you checked it.
- [ ] A review comment is answered in the code, not only in chat.
- [ ] A merge conflict is resolved by keeping both intentions, and the history is readable.
