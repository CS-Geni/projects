# A tiny useful language

Course: **Build Your Own Language** (Advanced, 52 hours).

Design, implement, test, and document a small language with functions, closures, and a REPL.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/crafting-language.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] The language has numbers, names, and function calls.
- [ ] A function can close over a value from outside.
- [ ] Bad syntax produces an error that points at the problem.
- [ ] A short program runs in a prompt you can type into.
- [ ] The language is documented on one page a new reader can try.
