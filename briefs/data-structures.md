# Route finder

Course: **Data Structures in Practice** (Intermediate, 34 hours).

Model a transit network as a graph and find useful routes while explaining the tradeoffs.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/data-structures.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] Stops and connections are a graph, not a pile of special cases.
- [ ] The program finds one useful route between two stops.
- [ ] You can say what gets slower as the network grows, and why you chose that structure.
