# Learning analytics database

Course: **Databases That Make Sense** (Intermediate, 30 hours).

Design and query a database for courses, enrollments, lessons, and progress events.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/database-design.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] Courses, learners, lessons, and progress events are tables with keys.
- [ ] A learner cannot be enrolled twice in the same course.
- [ ] One query counts lessons completed per course.
- [ ] The schema is drawn before the queries.
