# Community delivery optimizer

Course: **Algorithmic Problem Solving** (Intermediate, 42 hours).

Compare algorithms that schedule deliveries under time and capacity constraints.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/algorithmic-thinking.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] The same set of deliveries is scheduled by two different methods.
- [ ] You record time and capacity limits before you compare the methods.
- [ ] The write-up says which method you would ship, and one case where it is worse.
