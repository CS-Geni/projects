# Unix-style shell

Course: **How Operating Systems Work** (Advanced, 46 hours).

Build a small shell with processes, pipes, redirection, and careful error handling.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/operating-systems.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] The shell runs one program and waits for it.
- [ ] A pipe connects the output of one program to the input of the next.
- [ ] Output can be sent to a file.
- [ ] An empty command is refused, and a missing program is reported.
