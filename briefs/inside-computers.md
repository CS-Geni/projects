# Tiny virtual machine

Course: **Inside a Computer** (Intermediate, 38 hours).

Implement a small stack-based computer and run a custom instruction set.

Read the modules in [the study map](https://github.com/CS-Geni/curriculum/blob/main/courses/inside-computers.md), then build this on your own machine. The [learning site](https://cs-geni.github.io/public/) is where the lessons live.

## Done when

- [ ] The machine has a stack and a tiny instruction set you document.
- [ ] A program of your instructions adds two numbers and stops.
- [ ] An unknown instruction stops the machine with an error instead of guessing.
