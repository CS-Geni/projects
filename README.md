# CS-Geni projects

One capstone brief for each of the 15 [CS-Geni](https://cs-geni.github.io/public/) courses. A brief says what to build and when you are done. It does not include a finished solution.

Take the lessons on the site first. The module list for a course is in [cs-geni/curriculum](https://github.com/CS-Geni/curriculum). The first programming capstone has a tested core in [cs-geni/labs](https://github.com/CS-Geni/labs) (`src/planner.js`).

## How to use a brief

1. Read the course page until the project description matches something you can explain out loud.
2. Copy the checklist into your own notes and check an item only when it is true.
3. Keep the official book on its own site. Quote a sentence if you must, and follow that book's license.
4. For **Security review dossier**, describe assets, boundaries, and controls. Leave out exploit steps and payloads.
